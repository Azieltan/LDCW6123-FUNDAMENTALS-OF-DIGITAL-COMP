# Recording guide for a group presentation of up to 18 minutes

Allocate the sections among your actual group members. Each person should describe work they personally reviewed or changed. The lines below are prompts, not a claim that a recording exists.

## 0:00-1:30: Case and question
"We examine Netflix's original DVD-by-mail rental service in relation to Blockbuster stores. Our question is how a service that was worse at immediate pickup could attract customers and later challenge the incumbent model."

## 1:30-5:00: Christensen model
Explain an initial foothold, the conventional measure on which the entrant was worse, a different value network, improving performance, and wider market competition. Point to the incumbent and entrant explicitly. Clarify that streaming in 2007 was a later development rather than the original entry.

## 5:00-8:00: Poster
Walk through the dated evidence. In 1998 Netflix was operating DVD rental; by 2002 it had subscriptions, regional distribution and CineMatch. It launched streaming in 2007. The 2010 Blockbuster bankruptcy is an industry marker, not proof of a single cause. Netflix ended DVD shipments in 2023. Discuss increased choice and home convenience, plus the wait for postal delivery and later need for internet access.

## 8:00-12:00: Program demonstration
Compile with the README command. First choose Comedy, Relaxed, Over 100 minutes. Then choose Sci-Fi, Thoughtful, Up to 100 minutes. Enter invalid text and show the retry message. Explain the +2 mood and +1 length scoring rule, the fixed fictional catalogue and the fact that this is not Netflix's real algorithm.

## 12:00-14:00: Code, testing and Git
Show the input-validation function, recommendation loop and five passing test scenarios. Explain the actual Git commits, including which were AI-assisted draft preparation and which changes the group later made. Do not claim these draft commits are student contributions.

## 14:00-16:00: Conclusion
Summarise why the model applies, what the simple program demonstrates and its limitations. Invite questions. Check the duration is less than 18 minutes.

## Required final steps
Record in MPEG, MP4 or MOV; upload the real video to OneDrive; paste an accessible link into the PDF. Complete the supplied coversheet and a separate member declaration for each member. Include a repository or shared file link to the source code and Git log if the tutor requires URL-based access. Follow the institution's AI disclosure and originality rules.
