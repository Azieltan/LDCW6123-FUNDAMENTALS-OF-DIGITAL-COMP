# Netflix innovation life cycle project draft

Part 1 uses Christensen's disruptive innovation model to analyse Netflix's original DVD-by-mail entry into the video rental market. Part 2 is an original, offline C++ movie recommendation demonstration inspired by the convenience and discovery features of the service. Its small fictional catalogue and hand-written rules do not represent Netflix's real catalogue or recommendation algorithm.

Build: `g++ -std=c++17 -Wall -Wextra -pedantic src/main.cpp -o movie_assistant`
Run: `./movie_assistant`
The program needs no internet connection or personal data.

This project was prepared with generative AI. The git history documents the creation of this draft; it does not document student contributions. Group members should review, revise, and commit their own work before submission.
